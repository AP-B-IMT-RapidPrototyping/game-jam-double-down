# Design Doc

## Goin' Down

## Summary
je speelt als een diver die zo diep mogelijk in de zee gaat zonder dood te gaan aan pressure.

## Genre
Action Arcade Game

## Concept Pitch
Ontwijk de enemies en geraak zo diep mogelijk!
Maar wees voorzichting! Je moet op tijd terug naar boven gaan.

## Gameplay Mechanics
Arrow movement
Dodging

### Game Flow
Start spel, overleef terwijl je naar beneden gaat. Als je levend terug geraakt, bekijk je highscore en start opnieuw.

### Game Feel
Spanning bij het beslissen of je terug gaat of toch net iets verder zou pushen.

### Gameplay
Uitdagingen: meer en meer enemies hoe dieper je gaat.

### Mechanics
Raak de rode kubussen niet. 
Collect bubbles om je pressure te verminderen.
